# v3.0.0-rc.1 Release Notes

This release candidate introduces the daemon-owned Audio Analysis Worker and
the durable Runtime Job Queue.

## Breaking changes

- `fls-pilot.analysis-report.v1` is the only accepted analysis report contract.
  Missing, legacy, malformed, and unknown report versions are rejected.
- Legacy workflow-report adapters and Control Center report envelopes are
  removed. Existing in-memory or persisted legacy reports are discarded; no
  migration is provided.
- The synchronous `fl_analyze_audio` MCP tool is replaced by
  `fl_audio_analysis`, with `submit`, `status`, `result`, `cancel`, and `list`
  actions backed by Runtime jobs.
- Control Center consumes canonical Runtime responses and now exposes an Audio
  Evidence job panel.

## Audio analysis architecture

- Runtime job state is stored transactionally in SQLite WAL mode under
  `~/.fls-pilot/runtime/jobs.sqlite3`.
- Interrupted idempotent audio jobs are recovered deterministically according
  to retry, cancellation, and committed-artifact state.
- Feature artifacts and manifests are versioned, content-addressed, and
  atomically published under `~/.fls-pilot/audio-analysis/artifacts`.
- MCP and Control Center responses expose compact summaries and artifact
  references, not raw audio or unbounded feature arrays.
- Rendered audio evidence is linked explicitly to the current project and can
  strengthen Mix Review, Low-End Analysis, and Project Health.

## Safety and limitations

- Audio jobs read user-selected files only. Source audio is never moved,
  modified, or deleted.
- Audio analysis does not call the FL Studio bridge and does not open, save,
  render, or mutate FL Studio projects.
- Automatic render/export, plugin loading, playlist clip editing, destructive
  deletion, raw API escape hatches, and full-FLP restore remain unsupported.
- FL controller commands, controller handlers, protocol version 3, and the
  persistent-write rollback contract are unchanged.

## Versioning

- Python package version: `3.0.0rc1`
- Release tag: `v3.0.0-rc.1`
